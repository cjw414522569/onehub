# Bindings codegen policy (T097)

Pinned codegen version: **1.0.0**

The language bindings are produced from the stable C ABI in
`crates/abi-c` (`include/ssh_abi.h`), which is generated by
`scripts/generate-abi.mjs`. Regenerating must produce a byte-identical
header; `scripts/test-abi.mjs` enforces this (CI drift detection).

## Per-language status (Windows-first)

| Binding | Status | Verification on this host |
| --- | --- | --- |
| C ABI (`crates/abi-c`) | implemented, versioned | `scripts/test-abi.mjs`: regenerate->no diff, cdylib exports `ssh_abi_*`, Rust layout == header |
| Swift (`bindings/swift`) | interface-only | `blocked-unavailable-toolchain` (no Swift/Xcode) |
| Kotlin (`bindings/kotlin`) | interface-only | `blocked-unavailable-toolchain` (no Android/Gradle) |
| C# (`bindings/csharp`) | interface-only | `blocked-unavailable-toolchain` (no .NET/ClangSharp) |

The C link test is verified on Windows via layout-equivalence (Rust parses
the generated header and asserts sizes/offsets match the exported ABI) plus
cdylib symbol export checks; real C compilation links are exercised when a C
toolchain is available. Swift/Kotlin/C# link tests run on their native
toolchains and stay behind the approved `abi-c` interface boundary.
