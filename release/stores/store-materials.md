# Store listing materials (T167)

## Short description

A local-first, professional SSH client for desktop and mobile: terminal,
SFTP, port forwarding, and gateway access — with your keys kept on-device.

## Full description

- Secure SSH/SFTP with hardware-backed key storage.
- GPU-accelerated terminal rendering.
- Multi-session tabs and host library.
- Web access via your own gateway (no browser direct TCP).
